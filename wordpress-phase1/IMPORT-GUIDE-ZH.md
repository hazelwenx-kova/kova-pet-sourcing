# KOVA WordPress 第一阶段：测试站安装与编辑指南

此包只用于你的 `staging2.kovasourcing.com` 或本地测试站。不要上传到线上网站，也不要使用 SiteGround 的“推送到正式站”功能。

## 准备的文件

- `kova-theme/`：独立 WordPress 主题，包括原有字体、样式、动画、图片、页头和页脚。它替代 Blocksy，不是 Blocksy 子主题。
- `kova-content/`：分类管理、ACF Free 字段与初始内容导入插件。
- `packages/kova-theme.zip`、`packages/kova-content.zip`：可以通过 WordPress 后台上传的安装包。
- `VALIDATION.md`：已完成的测试、环境和仍需确认的事项。

不需要 Elementor 或 Elementor Pro。需要单独安装并启用 **Advanced Custom Fields 免费版**，本包没有捆绑 ACF，也不需要 ACF Pro。

## 仅在测试站操作

1. 在 SiteGround 为**测试站**备份数据库和文件。确认浏览器地址是 `staging2.kovasourcing.com/wp-admin/`，密码保护仍开启。不要进入正式站后台。
2. 在“插件 → 安装新插件”安装并启用 Advanced Custom Fields 免费版。然后上传并启用 `kova-content.zip`。保留已有其他插件；这一步不会设置或开启联系表单。
3. 在“外观 → 主题 → 安装主题 → 上传主题”上传 `kova-theme.zip`。可以先安装不启用，完成导入后再只在测试站启用它。它会替代测试站的 Blocksy 显示层，因此建议在备份后进行。
4. 打开“工具 → KOVA Phase 1 Import”。勾选测试站与备份确认框，点击 **Import missing Phase 1 content**。
5. 导入会创建两个**草稿页面**：Home、Cat Products；八个已发布的猫产品分类（没有独立公开分类网址）；以及 14 张媒体库图片。不会设置首页、创建菜单、修改邮件设置或自动发布页面。已有相同导入标记的内容会保留；可以安全重复运行。若某次因上传限制中断，修复原因后重试即可。
6. 在测试站启用 KOVA Sourcing 主题。打开“页面”，分别预览两个草稿。草稿之间的普通导航链接可能返回 404；完成完整导航测试前，需要由你将这两个页面**仅在密码保护的测试站发布**。
7. 发布后，在测试站“设置 → 阅读”选择静态首页 **Home**。勾选“不鼓励搜索引擎索引本站”；密码保护仍应保留。导入器不会自动更改这项设置。
8. 不设置自定义菜单时，主题自带原有七项导航。可在“外观 → 菜单”建立平级菜单，分配给 **KOVA primary navigation** 和 **KOVA footer navigation**。第一阶段不要添加下拉子菜单。剩余五页使用主题内的静态参考链接，不是可编辑的 WordPress 页面。

**不要手动创建另一个 Home 或 Cat Products 页面后再重复导入。**导入器只识别自己创建的记录，不会覆盖其他同名页面；若测试站原本有同名页面，WordPress 可能为导入页面分配不同网址。

## 日常编辑

### Home / Cat Products

打开对应页面，在 KOVA 内容区域使用三个标签页：

- **Page copy**：标题、介绍、服务说明、CTA 等文字。标题的换行和重点样式已固定；分别修改各段文字，不需要输入 HTML。
- **Buttons & links**：按钮名称与目的地。目的地可以是完整页面网址、原有 `.html` 参考链接或页面内 `#section`。不确定时保留当前链接。
- **Images**：从媒体库选择独立图片。替换已有图片时先点移除，再点 Add Image，选择新图片；“编辑”按钮主要用于编辑当前图片信息。

Home 页面还提供共享页脚文字字段。品牌 logo、导航样式、页面网格、字体、颜色、间距和响应式布局由主题固定。不要更换页面模板，或在普通内容编辑器中重新拼装页面。

图片的 Alt Text 在媒体库修改。建议使用与当前图片相近的构图和比例，避免重要主体位于裁切边缘。原拼图已拆分；替换单个分类图片不会影响其他分类。AI 图像说明暂时保留，等相关概念图全部替换后再审阅说明。

### 分类

打开 **Sourcing Categories**：

- 标题：产品分类名称。
- **Cat / Dog**：所属类型，可以管理猫和狗分类；第一阶段仅猫页读取并显示这些后台记录，狗页仍是静态参考。
- Category image：独立图片。
- Short introduction、Product options、Customization to discuss：对应卡片与折叠面板文字。
- Display order：数字越小越靠前。原有八个猫分类为 1–8。
- Display on category page：关闭即可隐藏；草稿分类也不会展示。

分类卡片保持固定结构，面板默认折叠。没有购物车、价格或购买功能。

## 测试清单

- 对比 Home 和 Cat Products 桌面、平板与手机的字体、间距、构图和折叠面板。
- 更改一句文字，保存后确认前台更新，再恢复。
- 替换一张分类图片，确认只有对应图片变化。
- 调整分类顺序、隐藏一个分类，确认前台变化，再恢复八个分类的原始顺序。
- 用手机打开菜单；用键盘 Tab / Enter 操作导航和分类折叠面板。
- 开启系统“减少动态效果”，确认没有滚动或缩放动画。
- 检查 Inquiry 按钮进入联系参考页，并携带分类信息；确认提交按钮不可用、开发提示仍显示。
- 再运行一次导入，确认没有重复页面、分类或媒体记录，已编辑内容没有被覆盖。

如遇缓存显示旧内容，仅清理**测试站**缓存。SiteGround 的 WebP 优化、缓存、当前 WordPress/PHP/ACF 版本仍需现场验证。

## 当前范围与恢复

仅 Home 和 Cat Products 完整迁移为可编辑模板。Dog Products、Sourcing Services、How We Work、About、Contact 暂为主题内静态参考副本，以保留导航和审核路径。这些副本不能通过后台编辑，也不应作为最终上线方案。

联系页没有配置 PHP/SMTP 接口，仍禁止发送。主题不包含已启用的邮件处理器，不会激活 Fluent Forms。询盘系统留待后续单独测试。

停用 KOVA Content 不会删除分类或媒体；重新启用可以恢复管理入口。插件没有自动清理数据库的卸载动作。删除页面或图片后想重置，请先确认你的编辑和备份，不要直接删除导入标记。发现导入项在回收站时，先恢复再导入。

需要回退测试站外观时，重新启用 Blocksy 并恢复原来的“阅读”设置或测试站备份。切换主题不会替你重新建立原页面内容。以上操作均不涉及线上站。
