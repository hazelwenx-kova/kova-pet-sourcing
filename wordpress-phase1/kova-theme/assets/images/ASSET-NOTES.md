# Review imagery

The six cat category panels and four dog category panels (also reused in the balanced hero and shared toy/grooming categories) are AI-generated photorealistic concept placeholders created for the KOVA redesign. They are not photographs of real supplier goods or proof of supplier relationships. The reference screenshots were used for general visual direction only; their images, text and branding were not reproduced.

All visual slots require licensed photographic replacements before launch. See the root README for filenames, panel order and replacement guidance. Keep licensing records for the chosen replacements and update accessible descriptions and concept notices accurately.
