# KOVA WordPress Phase 1 导入指南

本包只包含 **Home 和 Cat Products**。文件已准备好；没有连接、导入或修改 staging2.kovasourcing.com，也没有修改 live、表单或原静态站。

**以下操作仅在你批准后，由你或获授权管理员在密码保护的 staging 中执行。保持 live 不变，不使用 staging 的推送到 live 功能。**

## 1. 准备与备份

- 先备份 staging；确认 WordPress 至少为 6.8（Elementor 4.3.4 的源码最低要求），并核对实际 Blocksy 主题版本。Blocksy Companion 2.1.58 不是主题版本。
- 保持现有 Blocksy、Companion、Elementor Free 4.3.4 和 Fluent Forms；本阶段不需安装任何新插件或 Pro，不配置表单。
- 从 `wordpress-migration` 分支下载本目录。GitHub 可通过 **Code → Download ZIP** 下载分支，再取出本目录；也可逐个下载两份 JSON 和 CSS。不要把原静态站文件直接上传覆盖 WordPress 的 public_html。

## 2. 导入图片和字体

- WordPress **媒体 → 添加媒体文件**：上传 `assets/images/` 中 14 张 WebP，以及 `assets/kova-logo.png`。图片已经独立，不需要裁切整张合成图。
- 按 `assets/MEDIA-LIST.md` 填写媒体替代文字；全部仍是 AI 预览素材，页面的简短声明保留。
- 字体不需要 Pro 或字体插件：批准后通过 SiteGround staging 文件管理器，将 `assets/fonts/` 中两份 TTF 上传到 staging 的 `wp-content/uploads/kova-migration-fonts/`。保留字体许可记录。CSS 已使用这个路径；若放到其他路径，只改两条 `@font-face` URL。

## 3. 添加页面样式

- staging 的 **外观 → 自定义 → 额外 CSS**：追加 `kova-elementor.css` 的完整内容，保留已有 CSS。
- 此 CSS 只针对 `.kova-wp-page` 内的两页正文，统一布局、字体、间距与图像比例。没有页眉页脚替代代码、JavaScript 或表单提交代码。
- Elementor Free 没有 Pro 的逐 Widget Custom CSS 面板；因此使用 WordPress 的“额外 CSS”。日常替换文案和图片不需要改 CSS。
- 两页正文不包含全局导航和页脚，使用 Blocksy。设置参考 `Blocksy设置.md`；这些是建议，尚未应用。

## 4. 导入两份模板，建立草稿页

- 通过 Elementor **模板 → 保存的模板 → 导入模板**，导入：
  - `templates/kova-home.json`
  - `templates/kova-cat-products.json`
- JSON 是 Elementor 原生 page 模板格式 0.4。不要把 JSON 当图片上传到媒体库。
- **页面 → 新建页面**，建立 Home、Cat Products 两个草稿。建议 slug 为 `home`、`cat-products`。
- 页面布局选择 **Elementor Full Width**，不选 Canvas，避免隐藏 Blocksy 页眉页脚；关闭这两个页面的重复 WordPress 页面标题和侧栏。
- 点击 **使用 Elementor 编辑**，从模板库“我的模板”插入对应模板。菜单名称可能因界面语言略有差异。模板使用现有原生 Containers 与传统 Heading/Text Editor/Image/Button，以及 Free Nested Accordion，不要求 Atomic V4 专用组件或 Pro。
- 暂不设为首页，不发布页面，不调整全站菜单或 live 设置。保存草稿并预览。

## 5. 关联图片并确认可编辑

**重要：JSON 图片 URL 留空是有意的。** 密码保护的 staging 可能拒绝 Elementor 在服务器端下载外部图片。单独的 JSON 不能可靠地自动安装附件，因此这里不使用远程 GitHub 图、临时本机路径或未经验证的自动媒体导入。

- 打开 Elementor Navigator/结构面板，找到名称为 **“图片：xxx.webp”** 的原生 Image Widget。
- 点“选择图片”，在媒体库选同名文件。首页 8 个位置，Cat Products 10 个位置；文件只有 14 个，部分可共用。
- 对照媒体清单逐个关联。Image Widget 默认 Full；图像显示比例由已提供 CSS 保持。
- Heading、Text Editor、Button 和 Image 都可以单独编辑；Cat Products 的“Explore sourcing options”使用原生 Nested Accordion，内部产品选项与定制说明是可编辑 Heading/Text Editor。
- 折叠面板应默认全部关闭；在 Elementor 检查 **Default state → All collapsed**。不要为了显示内容把它们改成整页 HTML 或 iframe。

## 6. 验收后再进入 Phase 2

- 比较草稿的桌面、平板、手机布局，尤其首屏两张图、八张分类卡、折叠面板、字体和标题换行。
- 实际替换一张图片、一段文字、一个按钮链接，再保存草稿，确认编辑能保留。
- 测试折叠标题的 Enter/空格键、展开图标、移动端点按与焦点。
- 确认无水平溢出、AI 图像声明可见、无未经支持的经验/供应商声明。
- Phase 1 只创建两页；其余五页链接仍预留目标 slug，暂不能视为完整导航已通过。联系表单和 SMTP 不启用。
- 你确认两页成功导入、视觉和编辑通过后，再继续其余五页。发布和上线另行批准。
